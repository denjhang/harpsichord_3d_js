## 1. 决策：H5 优先，FreeCAD 降级为备选

**结论：本项目几何设计全部在 H5(Three.js) 中完成，直接导出 STL 切片打印，不经 FreeCAD。**

理由：
- 几何数据只此一份（JS 里的轮廓参数），进 FreeCAD 反而要做一次翻译、维护两份
- 琴体是"单实体 + 孔"的复杂度，用不到参数化历史树
- GLM 写 JS/H5 又快又稳，写 FreeCAD Python 反而易错（本项目已多次验证）
- 打印准备（切片、摆向、支撑）Bambu Studio 比 FreeCAD 专业

FreeCAD 仅在以下情况重新启用：
- 琴体需要拆件装配 + 配合公差设计
- 需要 FEM 应力验证（且按旧文档经验：FEM 自动化 API 不可靠，须 GUI 手动）

## 2. 当前模型状态（lyre_simulator.html 已验证）

结构（对照实物照片逐项确认）：
- ✅ 琴体：封闭实体挤出，顶部横梁闭合，厚 2.8cm
- ✅ 弦窗（上椭圆）+ 圆音孔（下部）
- ✅ 上端：仅金属音柱（柱体+柱头），**无横向木条**，弦缠绕在柱上
- ✅ 下端：**唯一一根品条**（立起木条）托弦；弦穿过面板背面穿孔，用铁扣（torus 环+结扣）固定在背面
- ✅ 弦平面悬空于面板前 1.05cm（由音柱和品条撑起，不贴面）
- ✅ 面板底部 7 个穿弦孔（r=0.3cm）与弦 x 坐标一一对齐
- ✅ 弦粗细分档：0.16cm(低音C4) → 0.06cm(高音D5)，Line2 worldUnits 渲染

声学（Karplus-Strong，**已调对，勿动**）：
- 阻尼公式：`damp = 0.5 + 0.493*exp(-freq/1800)`，时长 `min(3.2, 1.6+220/freq)`
- 1/5 拨弦点谐波滤波 + 木箱体低通(5.2kHz)+高频搁架衰减
- ⚠️ 曾尝试改为"按目标延音反推阻尼"（damp→0.9992+）导致声音彻底糊掉，已回退。
  **教训：KS 的衰减由"每周期 damp 一次"主导，微小的 damp 变化会被 freq*t 放大，调参一次只动一处并立刻试听。**

交互：
- 拖拽=旋转，Shift+拖拽=平移，滚轮=缩放（对齐 FreeCAD 操作习惯）
- 右上角导航组件（✅ 已对齐 FreeCAD）：真倒角立方体——面收缩后，12 条双面棱处画混色倒角条、8 个三面角处画三角倒角块（可见时最多 3 棱+1 角），全部可点击：面=正交视角、棱=两面对角视角、角=三面轴测视角（命中区叠加放大的不可见圆热区，易点击）；上下左右四个三角箭头（环绕/俯仰 45°）、左上右上弯曲箭头（绕视线滚转 30°，相机 up 支持 roll）、右下角小立方=切换坐标轴十字；所有控件带悬停手型与过渡动画
- ⚠️ 调试教训：IAB 页面 rAF 可能被节流挂起（渲染循环停摆→命中区为空、点击无效、截图超时）。导航组件命中注册已改为惰性重建（点击/悬停时若 hitItems 为空则同步 drawCube 一次），不依赖 rAF
- 视角锚点=热床面与物体中心的中点（target.y=琴体半高的1/4），窗口尺寸变化时 fitView() 自动适配缩放（半径取 max(床半宽, 琴体全高)，整床+立起琴体始终可见）
- 扫弦/点弦/键盘(ASDFGHJ 或 1-7)弹奏；弦振动为两端固定驻波（一次模+衰减更快的二三次模）

## 4. 本项目踩坑记录（给后续 AI）

1. **不要用裸几何**：直接摆 Part 图元没有设计意图。但"约束优先"在 H5 里体现为：轮廓用参数化 bezier 定义，弦位置由 GAP/X0 统一推导，孔与弦共享同一坐标源——改一处全局联动。
2. **弦振动必须是驻波**：两端固定、逐点 sin(πx/L) 包络，绝不是整根平移。拨弦瞬间叠加快速衰减的二三次模。
3. **弦必须脱离琴体**：实物结构是音柱(上)+品条(下)撑起弦平面 ≥1cm，每次改结构要切侧视图检查装配干涉。
4. **每改一处，浏览器实测截图验证**——本项目多次出现"代码看起来对、渲染/装配完全不对"。
5. Three.js Line2 (LineMaterial) 才支持线宽；普通 Line 的 linewidth 在 Windows 无效。
6. Line2 射线检测点击拨弦：raycast 对象用 `st.line`；改名变量后所有引用要同步（曾因此点击静默失效）。
7. **模块顶层 `const` 暂时性死区**：全局常量（BED/SCALE/H）相互引用必须按依赖顺序声明，提前引用会让整个 module 静默失败（画面全黑、HUD 占位为空），排查手段：fetch 页面源码 + blob import 捕获报错。
8. **canvas 贴图网格不显示先查坐标越界**：网格循环 `p=cx+i*5*px` 这种"步距×倍数"写法极易把线画到画布外，正确写法是 `p=cx+i*px, major=i%5===0`。
