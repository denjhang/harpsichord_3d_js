# 单键单弦 Harpsichord V0 清晰结构说明

之前的 CAD 模型看起来像一堆立方体零件，不适合理解原理。真正应该先理解的是这个最小机构：

```text
侧视图：

                         琴弦 string
固定端                                               调音端
  ●────────────────────────────────────────────────────●
                         ▲
                         │ 拨片 plectrum
                         │
                      ┌──┴──┐
                      │ jack│  垂直上下滑动
                      └──┬──┘
                         │
                         │ 被琴键后端顶起
                         │
手指按下 ↓               │
┌───────────────┬────────┴──────────┐
│   琴键前端     ▲ 支点 pivot        │ 琴键后端上升
└───────────────┴───────────────────┘

──────────────────────────────────────
                底座 base
```

## 核心动作

```text
按下琴键前端
    ↓
琴键绕支点转动
    ↓
琴键后端上升
    ↓
顶起 jack
    ↓
jack 上的拨片划过琴弦
    ↓
琴弦发声
```

## 最小原型只需要这些东西

### 1. 底座

一块长条底板，用来固定所有零件。

建议尺寸：

```text
长 220 mm
宽 50 mm
厚 8 mm
```

### 2. 琴弦

一根尼龙弦或尤克里里弦。

建议有效弦长：

```text
160 mm 左右
```

### 3. 固定端和调音端

左边固定弦，右边调音。

```text
左端：固定销 / 螺丝
右端：调音旋钮 / 调音钉
```

不要直接把弦拧在 PETG 上，最好用金属件。

### 4. 琴桥

一小条硬木或 PETG 条，放在弦下面，把振动传给共鸣板。

```text
位置：靠近固定端一点
高度：让弦离底座约 25 到 35 mm
```

### 5. 琴键

一个长条杠杆。

```text
键长：100 到 120 mm
键宽：12 到 14 mm
键厚：6 mm
支点：大约在键中间略靠前
```

### 6. Jack

一个竖直滑块，上面插拨片。

```text
高度：35 到 45 mm
宽度：5 mm
厚度：5 mm
```

Jack 在导轨中上下滑动。

### 7. 拨片

不要打印 PETG 拨片。用尼龙扎带剪一小片。

```text
长：6 到 10 mm
宽：2 到 3 mm
厚：0.3 到 0.5 mm
```

拨片应该略低于弦，jack 上升时刚好划过弦。

# 下一版 CAD 应该怎么画

下一版不要画一堆散件，应该画成**一体化教学模型**：

1. 灰色底座
2. 白色琴键
3. 黑色支点轴
4. 绿色 jack
5. 红色拨片
6. 银色琴弦
7. 棕色琴桥
8. 蓝色固定端
9. 红棕色调音端

并且每个零件都要明显分开、带文字标签。

重点不是漂亮，而是让人一眼看懂：

```text
按键 → 后端抬起 → 顶 jack → 拨片拨弦
```

# 设计修正建议

之前的模型问题：

1. 零件太多
2. 都是方块，看不出功能
3. 没有明确剖面关系
4. 弦、拨片、jack、琴键的相互作用不直观
5. 更像装配占位，不像教学原型

下一步应该重新建一个简化模型：

```text
MiniHarpsichord_V0_Clear.FCStd
```

只保留最核心机构，并做成侧视清晰结构。
